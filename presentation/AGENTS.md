# Convenciones de las presentaciones

- El programa del curso se llama **Panther Broker**, referencia elegida por el usuario a la UAM Azcapotzalco. No usar Fracción/Fraccion como marca.
- Cada presentación tiene una portada con un único título, sin subtítulo, etiquetas complementarias ni estimación de duración. El título de la introducción es **Introducción a las pruebas unitarias con JUnit**.
- Mantener una sola cabecera por diapositiva: sin antetítulos decorativos ni estimaciones de tiempo. Las notas pueden explicar las transiciones, sin duraciones. La planificación interna del guion queda fuera del deck.
- Conservar español de México, tema oscuro, código legible y notas para quien presenta.
- Mostrar código fiel a las fuentes y señalar si se omiten imports, menú u otras partes. Las salidas de ejecución deben proceder de las verificaciones reales del proyecto.
- Nombrar las pruebas con frases breves que describan comportamiento y condición; usar Given–When–Then para explicar la estructura, sin imponerlo en el nombre. Mantener los nombres de los ejemplos iguales a los de las fuentes Java.
