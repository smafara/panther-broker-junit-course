# Comprobar resultados

Activar el JDK del curso con `sdk env` desde la raíz. Ejecutar `./mvnw -f comprobar-resultados-junit/after/pom.xml test` (Windows: `mvnw.cmd`).

before contiene el caso conocido y una comprobación positiva deliberadamente insuficiente. after agrega la venta fraccionaria. Ambos pasan; las grabaciones reconstruyen el defecto `/ 10` en una copia temporal. No copiar fórmulas del código para obtener el esperado.

La práctica propone una cuenta ya equilibrada: esperado0. Las limitaciones numéricas del ejemplo anterior permanecen; la tolerancia es una diferencia absoluta permitida, no una política de dinero.
